# Contribuindo

Obrigado pelo interesse! Este projeto é **open source** sob a licença **MIT**.

## Como contribuir

1. Abra uma issue descrevendo o problema ou a ideia.
2. Faça um fork e crie uma branch (`feat/...` ou `fix/...`).
3. Rode os testes do projeto (o comando está no README).
4. Abra um pull request explicando o que mudou e como testar.
5. Ao enviar, você concorda em licenciar sua contribuição sob a MIT e declara ter o direito de fazê-lo.

## Segurança

- Nunca envie segredos, chaves, cookies, tokens, dados de terceiros ou achados reais em issues/PRs.
- Ferramentas de segurança: use apenas em alvos que você possui ou para os quais tem autorização escrita.
- Respeite o escopo, o rate limit e as regras de cada programa.
